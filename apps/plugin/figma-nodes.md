# Figma Node Type

## Container Nodes

FRAME - Basic frame container with layout properties
GROUP - Groups multiple nodes together (no layout)
COMPONENT - Master component definition
COMPONENT_SET - Container for component variants
INSTANCE - Instance of a component

## Shape Nodes

RECTANGLE - Rectangle with optional corner radius
ELLIPSE - Ellipse/circle shape
POLYGON - Regular polygon (triangle, pentagon, etc.)
STAR - Star shape with customizable points
LINE - Straight line
VECTOR - Custom vector path
BOOLEAN_OPERATION - Result of boolean operations (union, subtract, intersect, exclude)

## Text Nodes

TEXT - Text layer with formatting
TABLE - Table element
WASHI_TAPE - Washi tape decoration (FigJam)

## Special Nodes

SLICE - Export slice area
